# 🔥 Sanji Gomes - Personal Trainer 🦵

Uma Landing Page responsiva e interativa desenvolvida como projeto de estudo prático de desenvolvimento web. O layout simula a página de vendas e captação de alunos de um personal trainer, utilizando uma temática descontraída inspirada no universo do anime One Piece.

## 🚀 Visão Geral

O objetivo principal deste projeto foi consolidar conhecimentos em marcação semântica e estilização avançada, construindo uma interface do zero sem o uso de frameworks CSS. A página conta com seções de apresentação, serviços, benefícios, prova social (depoimentos) e um formulário de contato.

## 🛠️ Tecnologias e Técnicas Utilizadas

*   **HTML5:** Estruturação semântica do conteúdo utilizando tags apropriadas (`<section>`, `<form>`).
*   **CSS3:**
    *   **Layout Responsivo:** Utilização nativa de `Flexbox` (com `flex-wrap` e propriedades de crescimento) para adaptar os cards de serviços e depoimentos a qualquer tamanho de tela.
    *   **Micro-interações (Hover):** Criação de animações suaves de transição (`transition: all 0.4s ease`). Os cards de serviço possuem uma mecânica de "revelação", onde a descrição oculta (`max-height: 0`, `opacity: 0`) se expande e aparece de forma fluida ao passar o mouse.
    *   **Design Visual:** Uso de gradientes lineares mesclados com imagens de fundo, sombras dinâmicas (`box-shadow`) e uma paleta de cores focada no alto contraste (Fundo escuro com detalhes em dourado/amarelo `#F2A900`).
*   **Tipografia:** Integração com a Google Fonts utilizando a família *Montserrat*.

## ⚙️ Como visualizar

O projeto é puramente front-end estático (Client-side). Para visualizá-lo:

1. Faça o clone deste repositório.
2. Abra o arquivo `index.html` em qualquer navegador web de sua preferência.
